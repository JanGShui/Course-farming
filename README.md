## 项目简介

这是一个运行在 Tampermonkey / Violentmonkey 中的用户脚本（userscript）。它通过观察页面 DOM，实现以下功能：

- 轮询课程目录，自动切换到下一个未完成的小节；
- 检测视频暂停、播放卡死等状态，并尝试恢复播放；
- 跳过已经出现完成标记（绿勾）的小节；
- 对页面可见性、播放倍速等前端状态做处理。

脚本只做浏览器前端自动化，不包含服务端绕过、接口签名破解或数据篡改。它是否有效，取决于课程平台的前端实现和风控策略。

> 本项目是一个技术示例，不是课程平台的官方工具，也未获得任何平台的授权或认可。

## 功能特性

- **目录巡检**：按固定间隔检查课程小节和当前激活项。
- **自动连播**：当前小节结束后自动进入下一个未完成小节。
- **完成跳过**：识别已完成标记，避免重复播放。
- **播放保活**：视频暂停或长时间无进度时尝试重新播放。
- **倍速处理**：设置实际播放倍速，同时让前端读取到配置的伪造值。
- **可配置选择器**：站点改版后，集中修改 `TARGET_PROFILE` 即可适配。

## 环境要求

- 浏览器：Chrome / Edge / Firefox 的较新版本；
- 脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)；
- 能够在目标课程页面打开开发者工具（可选，用于查看日志和调试选择器）。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 在管理器中新建一个用户脚本。
3. 将 [Course.js](Course.js) 的全部内容粘贴进去。
4. **修改 `@match`**，把它改成你的课程站点地址，例如：

   ```js
   // @match https://course.example.com/*
   ```

   如果课程页面在子域名下，可以使用：

   ```js
   // @match https://*.example.com/*
   ```

   不要使用 `*://*/*` 这类宽泛匹配，以免脚本在无关网站上运行。
5. 保存脚本，打开课程页面并刷新。
6. 打开浏览器控制台，确认能看到 `[Core]` 开头的日志。

> 如果脚本没有任何日志，优先检查 `@match` 是否匹配当前地址、课程目录是否已经渲染，以及脚本管理器是否启用了该脚本。

## 配置

所有站点相关的配置都在 `Course.js` 的 `TARGET_PROFILE` 中：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `bootContainer` | `.content_box___Ue-Ix` | 顶层目录容器，用于判断页面是否加载完成 |
| `unitItems` | `a.units_wrap_box___3DqST` | 课程小节链接集合 |
| `activeClass` | `units_active_box___n73iR` | 当前播放小节的激活类名 |
| `finishedSelector` | `.study_success_svg___Dc7SQ` | 100% 完成标记（绿勾） |
| `clickSubTarget` | `''` | 点击目标；为空表示直接点击小节 `<a>` 本身 |
| `videoSelector` | `video` | 视频元素选择器 |
| `targetRate` | `1.5` | 实际设置的播放倍速 |
| `spoofedRate` | `1.0` | 页面读取 `video.playbackRate` 时返回的值 |
| `skipFinished` | `true` | 是否跳过已完成小节 |
| `tickIntervalMs` | `1000` | 巡检间隔（毫秒） |
| `stallThresholdMs` | `7000` | 判定为播放卡死的无进度时长（毫秒） |

这些类名带有构建工具生成的哈希后缀，站点重新发布后很可能会变化。修改选择器时，建议在浏览器开发者工具中重新确认元素，而不是直接猜测。

## 使用

1. 打开课程页面，确保侧边栏目录已经显示。
2. 脚本会自动开始巡检，并在控制台输出切换和播放日志。
3. 如需停止脚本，可以在 Tampermonkey 中禁用该脚本，或在页面控制台执行：

   ```js
   window.__RED_AUTO_CORE__?.destroy();
   ```

4. 修改配置后，需要重新加载页面。

## 已知限制

- **选择器是站点专用的**：平台改版、类名哈希变化、目录结构变化都会导致脚本失效。
- **跨域 iframe 不支持**：脚本可以尝试读取同源 iframe，但无法访问跨域 iframe 的 DOM。
- **Shadow DOM 未覆盖**：如果播放器或目录位于 Shadow DOM 中，需要额外适配。
- **后台标签页节流**：浏览器会限制后台页面的定时器频率，前端可见性伪装不能解除这种节流。
- **服务端仍可能检测异常**：平台可能根据播放时长、请求间隔、心跳、进度上报等数据判断异常，前端脚本无法保证绕过。
- **自动播放限制**：浏览器可能阻止有声自动播放；脚本在必要时会尝试静音播放。
- **点击行为不确定**：某些站点的 `<a>` 会触发整页刷新或新标签页，实际行为取决于站点实现。
- **不保证完成结果**：完成标记、学时上报和成绩认定以平台服务端为准。
- **不承诺维护**：原作者不保证脚本在平台改版后继续可用，详见“维护状态”。
